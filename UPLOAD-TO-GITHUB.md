# Upload to GitHub

1. Extract this package.
2. Open the `screenshots/` and project files.
3. Upload the folder contents to:
   `yogaagungpratama/yogaagungpratama`
4. Keep `README.md` at the repository root.
5. For the portfolio profile, place this project under:
   `projects/email-monitoring/`
6. Upload the `screenshots/` folder inside that project.
7. Commit the changes.

Recommended GitHub structure:

```text
yogaagungpratama/
├── README.md
├── certifications/
├── projects/
│   └── email-monitoring/
│       ├── README.md
│       ├── screenshots/
│       └── docs/
└── SECURITY.md
```
