Monitoring · AutomationPROJECT / 01

Email Monitoring & Infrastructure Automation

Pemantauan penggunaan mailbox dan kuota melalui cPanel UAPI, dengan layanan Python di Ubuntu Server serta laporan dan notifikasi Telegram.

Problem Mailbox storage across several cPanel servers was hard to track in one place, so full mailboxes could go unnoticed.

Solution A Python service reads usage through cPanel UAPI, sorts each mailbox into a status level, and sends Telegram reports and alerts. A dashboard shows everything at a glance.
