How it works

The automation behind this dashboard (see the project documentation for details)

1. cPanel UAPIReads mailbox usage and quota from each cPanel server.
2. Python serviceRuns on Ubuntu Server, collects and stores the data.
3. Status rulesClassifies each mailbox: normal, warning, high, critical.
4. Telegram botSends scheduled reports and alert notifications.
5. Home AssistantAutomation hooks and device control; private access through Tailscale.
Sample Telegram alert: ⚠️ CRITICAL – support@demo-company.example is at 98% of its 5 GB quota (source: Main server). Please clean up or increase the quota.
